## 🔬 About Me

I am a scientific researcher and programming enthusiast from Brazil with a deep focus on the exact sciences. My work bridges the gap between theoretical mathematics and applied computational models. 

Currently, this repository serves as a hub for my scientific programming scripts—primarily written in **Julia** and **Python**—designed to analyze the non-linear dynamic behavior of systems across engineering, physics, mathematics, chemistry, and biology. 

* 🎓 **Academic Background:** 
  * **B.S. in Mathematics** - State University of Ponta Grossa (2007)
  * **M.S. in Applied Chemistry** - State University of Ponta Grossa (2010)
  * **Ph.D. in Sciences** - State University of Ponta Grossa (2016)
* 🔭 **Research Interests:** Mathematical Physics, Complex Systems, Dynamical Systems, Fractional Calculus, Computational Physics, and Molecular Dynamics.
* 🌱 **Currently focusing on:** Advancing my scientific scripts in Julia and Python for complex numerical analyses.
